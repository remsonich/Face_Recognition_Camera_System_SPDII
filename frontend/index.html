        កំណត់ Telegram Intruder Alert

        ព័ត៌មាន Bot និង Chat ID

        របៀបបង្កើត Telegram Bot (ត្រឹមតែ ១ នាទី)

        1. បើកកម្មវិធី Telegram ហើយស្វែងរក @BotFather
        2. ផ្ញើសារ /newbot ហើយដាក់ឈ្មោះ bot របស់អ្នក
        3. អ្នកនឹងទទួលបាន Bot Token — ចម្លងវាមកដាក់ក្នុងប្រអប់ខាងឆ្វេង
        4. ស្វែងរក @userinfobot ក្នុង Telegram ឬចុច Start លើ Bot របស់អ្នក
        5. អ្នកនឹងឃើញ Id (Chat ID) របស់អ្នក — ចម្លងវាមកដាក់ក្នុងប្រអប់ Chat ID
        6. ចុចប៊ូតុង «ផ្ញើសារសាកល្បង» ដើម្បីបញ្ជាក់ការតភ្ជាប់
